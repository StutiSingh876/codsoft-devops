# Nginx Web Server Project

## Overview

This project demonstrates the installation and configuration of an Nginx web server on Linux using WSL.

The project includes:

- Nginx installation and configuration
- Static website hosting
- Multiple virtual hosts
- Custom 404 and 50x error pages
- Server accessibility testing
- Performance testing using ApacheBench
